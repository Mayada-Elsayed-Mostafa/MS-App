# 🧠 MS Detection App

Android app to assist in Multiple Sclerosis (MS) detection using on-device machine learning and TensorFlow Lite.

## 💡 Project Goal
Make MS detection more accessible using explainable, mobile-based AI.

## 🧠 ML Model
- Trained with TensorFlow
- Converted to TFLite for on-device inference

## 🛠️ Tech Stack
- Kotlin, Jetpack Compose
- MVVM, TensorFlow Lite
- Python for model training

## 🎓 Graduation Project
Grade: A+  
Part of the "Interpretable Deep Learning Framework for MS" research.
